# New Possibilities

A lightweight, mobile-responsive landing page for April Fletcher's private New Possibilities consultation.

## Files

- `index.html` — complete standalone website (HTML and CSS)
- `images/april-bass.png` — one small supporting portrait/performance photograph

## Preview locally

Download or clone the repository and open `index.html` in a browser. No build step, package manager or server is required.

## Publishing

This repository is private and is not deployed by these commits. The site can be moved to any static web host later by uploading `index.html` and the `images` folder. Do not change hosting, domain records or ad links before reviewing the final site.
